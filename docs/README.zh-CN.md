# 岗位技能雷达

面向美国、中国的实习与应届技术岗位，把招聘要求转成可筛选、可追溯的技能统计。

## 已实现

- NVIDIA、Apple、腾讯官网采集器；其他目标公司公开标注接入状态。
- AI／机器学习、计算机视觉、3D／SLAM、ECE 软件四个可重叠方向。
- 中英技能别名归一化，以及必需／加分／仅提及／无法判断四类证据。
- 中英界面、岗位筛选、跨市场对比、原文链接和 CSV 导出。
- GitHub Actions 每天 07:23 UTC 自动更新，GitHub Pages 展示，独立 data 分支保存数据。

## 本地使用

需要 Python 3.11+、系统 curl、Node.js 24+。无需模型 API 密钥。

```sh
python3 -m radar.cli
cd web
npm ci
npm run dev
```

直接用仓库自带的真实快照也能打开网页，不必先采集。只更新指定来源：

```sh
python3 -m radar.cli --sources apple tencent
```

采集退出码 2 表示存在失败或部分更新，查看终端日志及网页“数据来源”。有效记录仍会保存；失败来源不会删除已有岗位。NVIDIA 接口可能返回只有编号、缺少标题和链接的记录，此时整次扫描标记为部分更新，不据此判断岗位下线。

## 自动更新

开启仓库 Actions；在 Settings → Pages 选择 GitHub Actions；运行 Collect and deploy。之后每天会自动检查新的岗位与要求变更。调度可能延迟；连续两次完整成功采集均未看到的岗位才标记下线。

“发现技能”统计来自描述正文，不从岗位名称推测。默认仅显示实习与应届；级别不明确的岗位可以通过筛选查看。国外公司的中国岗位也按实际工作地点计入中国。

## 评估与边界

阅读 [分析方法](methodology.md) 和 [来源验证](sources.md)。评估样本若标为 agent-reviewed，表示代理审阅，不能当成人工验收。40 条真人标注及 90% 精确率目标在独立人审完成前不宣称达标。

数据代表已接入公司的样本，不代表整个就业市场。项目不提供自动投递，不收集求职者个人资料。源代码为 MIT，招聘内容的版权归原公司。
