# Data provenance

Job Skill Radar processes publicly visible employer recruitment information for job-search research. Each record links to its original posting and records observation timestamps. All skill evidence is quoted from that posting's description.

The MIT license applies to this project's code, configuration structure and original documentation, not to employer recruitment text, names, logos or other third-party material. This project does not grant independent rights to republish those materials. CSV exports retain source links and should be used with the same provenance considerations.

No applicant account, résumé, contact list or other personal application information is collected. Raw source responses and full descriptions are local, ignored debugging artifacts and are not part of the public repository. Source response bodies are never inserted as executable HTML in the dashboard.

To report an incorrect extraction, include the source URL and the relevant short evidence sentence in an issue. To request removal of an excerpt, identify its source job ID and URL. This is an independent project, not affiliated with the employers.
